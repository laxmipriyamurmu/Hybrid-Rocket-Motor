# Computational Performance Analysis and Development of a 100 N-Class Hybrid Rocket Motor

## Project Overview

This project focused on the design, computational performance analysis, and prototype development of a 100 N-class hybrid rocket motor utilizing paraffin wax-based fuel enhanced with Aluminium (Al) and Lithium Borohydride (LiBH₄) additives and Liquid Oxygen (LOX) as the oxidizer.

The objective was to investigate the influence of energetic additives on combustion characteristics and propulsion performance while developing a practical hybrid rocket propulsion system.

---

## Objectives

* Design a 100 N-class hybrid rocket motor.
* Perform thermochemical performance analysis using NASA CEA.
* Evaluate the effects of Aluminium and LiBH₄ additives.
* Design propulsion subsystems including injector, combustion chamber, fuel grain, and nozzle.
* Develop and validate a functional prototype.

## Methodology

### Propulsion System Design

* Fuel grain design
* Injector design
* Combustion chamber sizing
* Converging-diverging nozzle design

### Computational Analysis

NASA CEA was used to estimate:

* Combustion temperature
* Exhaust velocity
* Characteristic velocity
* Specific impulse
* Propellant performance

### Performance Evaluation

Comparative analysis was performed to evaluate the influence of Aluminium and Lithium Borohydride additives on propulsion efficiency and combustion performance.
